## ⚠️ 副作用与边界（市场审核披露）

- **文件**：生成交接文档写入仓库
- **网络**：不访问外部网络
- **命令**：不直接执行命令
- **凭据/敏感数据**：处理前会脱敏 API 密钥、密码、个人信息等敏感内容
- **人工确认**：所有高影响操作均由用户确认后执行。


把当前对话总结成一份交接文档，让一个全新的 Agent 能接着把活干下去。保存到用户操作系统的临时目录——不要存进当前工作区。

在文档里加一节"建议技能"，列出下一个 Agent 应该用 Skill 工具调用哪些技能。

不要重复其他产物（规格、计划、ADR、issue、提交、diff）已经捕获的内容。改用路径或 URL 引用它们。

脱敏任何敏感信息，比如 API 密钥、密码或个人信息。

如果用户传了参数，把它当作对下一次会话重点的描述，并据此调整文档。
