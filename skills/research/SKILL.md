name: research
description: 根据高信任度的一手来源调查问题，并将调查结果捕获为仓库中的 Markdown 文件。当用户想要研究某个主题、收集文档或 API 事实，或者把阅读跑腿工作委托给后台代理时使用。
---

启动一个**后台代理**来做研究，这样它读资料的时候你继续干活。

它的工作：

1. 用**一手来源**调查问题——官方文档、源代码、规格、第一方 API——而不是二手转述。每个论断都要追溯到拥有它的来源。
2. 把发现写进一个单独的 Markdown 文件，每条论断都注明出处。
3. 存到仓库本来就存放这类笔记的地方；遵循现有惯例，如果没有惯例，就放到一个合理的位置并说明放在哪。
